# 山陰・宮島 ドライブ

2026年8月18日〜19日、大阪から山陰・宮島へのドライブ用ページ。
スマホで開く前提。オフラインでも表示できます。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 本体。旅程・SA/PA・情報・持ち物のすべてがここに入っています |
| `sw.js` | オフライン用。一度開けば圏外でも表示できます |
| `manifest.json` | ホーム画面に追加したときの設定 |
| `icon.png` | アプリアイコン |

外部ライブラリは使っていません。4ファイルを同じ階層に置くだけで動きます。

## 公開のしかた

### Vercel

1. GitHubに新しいリポジトリを作り、4ファイルをリポジトリ直下に置く
2. Vercelで「Add New → Project」からそのリポジトリを選ぶ
3. フレームワークの設定は不要（Other のまま）。そのままDeploy

以降はpushするたびに自動で更新されます。

### GitHub Pages

1. リポジトリ直下に4ファイルを置く
2. Settings → Pages → Source を `main` ブランチのルートに設定
3. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で公開されます

どちらもhttpsで配信されるので、オフライン機能が有効になります。

## 家族への渡し方

公開URLを送るだけです。アカウントもアプリのインストールも要りません。

iPhoneなら Safari で開いて共有ボタン →「ホーム画面に追加」、
Androidなら Chrome のメニュー →「アプリをインストール」で、
アイコンから直接起動できるようになります。

**出発前に一度、家族全員に開いてもらってください。** 一度開けば内容が端末に保存され、
電波の届かない山間部でも表示できます。

## 使い方

画面下に4つのタブがあります。

- **予定** — 現在時刻に合わせて、いまの予定が緑にハイライトされます
- **走行** — ICで高速に乗ったら「乗った」を押すと、次のSA/PAまであと何分かが出ます
- **情報** — 宿の連絡先、給油できない区間、費用
- **持ち物** — チェックは各自の端末に保存されます

## 直したいとき

すべて `index.html` の中にあります。

- **旅程を変える** → `const DAYS = {...}` を編集
- **SA/PAを変える** → `const LEGS = [...]` を編集（`m` は乗ってからの経過分）
- **持ち物を変える** → `const PACK = [...]` を編集
- **宿の電話番号** → `tel:05030331039` と、その隣の表示文字列の2か所

**内容を更新したら、`sw.js` の `CACHE = "sanin-miyajima-v1"` の数字を上げてください。**
上げないと、すでに開いた端末に古い画面が残り続けます。

## 注意

- 宿の電話番号は予約サイト経由の番号の可能性があります。公式サイトの直通番号を確認して差し替えてください
- 時刻はすべて渋滞を見込まない計算値です
- 高速料金はETC通常料金の概算です（8/18・19は平日のため休日割引は適用されません）
